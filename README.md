# houseCatch

청약홈에 매번 들어가서 클릭하지 않아도 되도록, **무순위 / 임의공급 / 불법행위재공급** 물량만 모아서 한 화면에 보여주는 대시보드입니다.

모집공고문의 공급금액과 실거래가를 비교해 **예상 시세차익**까지 같이 보여줍니다.

- 물량·일정: 청약홈 [APT잔여세대 분양정보](https://www.applyhome.co.kr/ai/aia/selectAPTRemndrLttotPblancListView.do) 목록 + 각 공고의 입주자모집공고 상세
- 시세: [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/) — 최근 1년 아파트 매매 + 분양/입주권
- 의존성 없음 (Node 20+ 내장 `fetch`/`http`만 사용)

> **네이버 부동산을 안 쓰는 이유** — 네이버 부동산 API(`new.land.naver.com`)는 서버에서 호출하면
> `429 TOO_MANY_REQUESTS`로 막혀서 시세 근거로 쓸 수 없습니다. 대신 같은 성격의 공식 자료인
> 국토부 실거래가를 씁니다. 호가를 직접 보고 싶으면 카드마다 있는 **네이버 시세** 링크로 바로 넘어가면 됩니다.

## 실행

```bash
npm start
```

http://localhost:4173 을 열면 됩니다. 처음 실행하면 데이터가 없어서 자동으로 한 번 수집합니다(1~2분).

기본으로 60분마다 백그라운드 갱신합니다. 바꾸려면:

```bash
AUTO_REFRESH_MIN=0 PORT=8080 npm start
```

## 수집만 따로 돌리기

```bash
npm run scrape
```

기본 범위는 **3개월 전 ~ 다음 달**입니다. 직접 지정하려면(청약홈 제한상 최대 12개월):

```bash
node src/scrape.js 202601 202609
```

결과는 `data/latest.json`에 저장됩니다. 상세 페이지는 `data/detail-cache.json`에, 실거래 자료는 `data/molit/`에 캐시되고, 접수가 끝나지 않은 공고만 매번 다시 조회합니다.

시세 비교를 빼고 목록만 빠르게 받으려면:

```bash
SKIP_MARKET=1 npm run scrape
```

## 시세차익은 어떻게 계산하나

주택형(전용면적)마다 국토부 실거래를 찾아 **중앙값**을 시세로 잡고, `시세 − 분양가`를 차익으로 봅니다.
같은 단지 거래가 없으면 아래 순서로 범위를 넓히고, **어느 단계에서 나온 값인지 카드에 항상 같이 표시**합니다.

| 단계 | 조건 |
| --- | --- |
| 같은 단지 · 같은 평형 | 단지명 일치 + 전용면적 ±0.6㎡ |
| 같은 단지 · 비슷한 평형 | 단지명 일치 + 전용면적 ±10% |
| 같은 동 · 비슷한 평형 | 같은 법정동 + 전용면적 ±7% |
| 같은 시군구 · 비슷한 평형 | 같은 시군구 + 전용면적 ±7% |

다른 단지와 비교하는 아래 두 단계에서는 **분양권 거래를 우선 쓰고, 없으면 준공 8년 이내 아파트만** 봅니다.
신축 분양가를 20년 된 구축 매매가와 견주면 차익이 엉뚱하게 나오기 때문입니다.

카드에 크게 뜨는 분양가·시세·차익은 모두 **대표 주택형 하나**(분양가와 시세가 둘 다 있는 것 중 세대수가 가장 많은 평형) 기준입니다.
평형별 값은 카드를 눌러 상세에서 볼 수 있습니다.

무순위(사후)처럼 분양가가 "사업주체 문의"인 공고는 차익 없이 시세만 표시합니다.

## 파일 하나로 뽑기

서버 없이 열거나 폰으로 보내고 싶을 때:

```bash
npm run build:static
```

- `dist/housecatch-snapshot.html` — 더블클릭하면 바로 열리는 완성 파일
- `dist/housecatch-artifact.html` — Artifact로 올릴 때 쓰는 body 조각

데이터가 파일 안에 박히므로 그 시점의 스냅샷입니다. 스냅샷에서는 새로고침 버튼이 동작하지 않습니다.

## 화면

- **요약 타일** — 지금 접수중 / 접수예정 / 전체 수집량 / 가장 임박한 청약
- **카드** — 공급세대수와 예상 시세차익을 크게, `분양가 → 시세` 한 줄과 비교 기준·거래 건수를 그 아래에. 클릭하면 상세 시트(평형별 세대수·분양가·시세·차익, 시세 근거, 모집공고문 PDF, 네이버 부동산, 지도)
- **캘린더** — 청약 접수기간이 걸쳐 있는 날마다 물량을 색으로 구분해 표시
- **표** — 물량·분양가·시세·차익·비교 기준·일정을 한눈에 비교
- 필터: 접수 상태 / 공급 구분 / 지역 / 최소 물량 / 시세비교 단계 / 검색어, 정렬에 **시세차익 큰순**. ⭐ 찜은 브라우저에 저장됩니다. `/` 키로 검색창 포커스.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/applyhome.js` | 청약홈 요청 + HTML 파싱 (목록·상세·청약캘린더) |
| `src/molit.js` | 국토부 실거래가 조회 (지역 코드, 실거래 CSV, 법정동 색인) |
| `src/market.js` | 공고 주소 → 시군구 매칭, 평형별 시세·시세차익 계산 |
| `src/scrape.js` | 목록·상세·시세를 합쳐 `data/latest.json` 생성, 캐시 관리 |
| `src/server.js` | 정적 파일 + `/api/data`, `/api/refresh` |
| `src/buildStatic.js` | 데이터를 인라인한 단일 HTML 생성 |
| `public/` | 화면 (의존성 없는 순수 HTML/CSS/JS) |

## 주의

- 청약홈은 `User-Agent` 헤더가 없으면 404를 돌려줍니다 (`src/applyhome.js`에서 항상 붙임).
- 상세 페이지는 공급 유형별로 표 구조가 다릅니다. 헤더 이름으로 컬럼 역할(세대수·분양가·입주예정월·비고)을 판별하고, 불법행위재공급은 "공급대상" 표에서 주택형별 세대수를 가져옵니다.
- 국토부 실거래 조회는 **범위가 최대 1년**입니다. 넘기면 CSV 대신 JSON 에러가 오므로 `src/molit.js`에서 content-type을 확인합니다. CSV는 EUC-KR입니다.
- 행정구역 개편(예: 인천 서구 → 검단구·서해구)으로 공고문의 옛 구 이름이 코드표에 없을 수 있어, 그럴 때는 법정동 이름으로 시군구를 다시 찾습니다.
- **코드를 고친 뒤에는 서버를 다시 띄우세요.** Node가 모듈을 메모리에 물고 있어서, 돌아가던 서버로 `/api/refresh`를 하면 예전 파서가 그대로 쓰입니다.
- 시세차익은 참고 지표입니다. 실거래가는 계약일 기준 신고분이라 시차가 있고, 층·향·동에 따라 실제 가격은 크게 다릅니다. **신청 전에는 반드시 입주자모집공고 원문과 현장 시세를 확인하세요.**
